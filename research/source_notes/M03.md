## Methodological procedure established from available search snippets

Based on multiple converging secondary sources (PRISMA statement website prisma-statement.org, PMC copies PMC8008539/PMC8005924, library guides from UNC Chapel Hill and Temple University, and general search synopses):

**1. Purpose.** PRISMA 2020 is an official, peer-reviewed reporting guideline (not a conduct methodology per se) for systematic reviews. It updates the 2009 PRISMA statement to reflect methodological and terminological advances, and its purpose is to help authors report systematic reviews transparently, completely, and accurately — it standardizes what must be reported, not necessarily how the underlying search/synthesis must be conducted.

**2. Core components, per convergent search summaries:**
- A **27-item checklist** covering the elements a systematic review report should contain (e.g., title, abstract, rationale, objectives, eligibility criteria, information sources, search strategy, selection process, data collection process, risk-of-bias assessment, synthesis methods, results, discussion, funding/registration/protocol information). The exact item-by-item breakdown was not independently re-derived from a directly fetched checklist table in this search round, so the general existence and count (27 items) is corroborated by multiple sources, but the precise wording of each item should be checked against the primary checklist (or the companion Explanation & Elaboration paper, M05) before being reproduced in the thesis.
- An **abstract checklist**, a shorter companion checklist specifically for structuring the abstract of a systematic review report.
- A **PRISMA flow diagram**, used to visually document the flow of records through the review process. Multiple sources converge on a four-phase structure:
  1. **Identification** — total records identified from database searches (and other sources), followed by the number of records remaining after duplicates are removed.
  2. **Screening** — records screened (typically by title/abstract), with the number excluded at this stage recorded (and reasons, where feasible).
  3. **Eligibility** — full-text reports sought/assessed for eligibility, with the number of full texts excluded and the specific reasons for exclusion documented (e.g., wrong population, wrong outcome, wrong study design — illustrative categories; the thesis's own reasons would be specific to reshoring-scope criteria, e.g., not genuine reshoring, no Asian host country, not firm-level).
  4. **Included** — the final number of studies/reports included in the review (and, where relevant, in any quantitative synthesis).

**3. Relevance to this thesis.** PRISMA 2020 is the standard tool the Methodology chapter would use to (a) present a flow diagram showing how the initial database search yielded to the final ~21-source formal analytical sample plus the additional context/methodology sources, and (b) structure the write-up of eligibility criteria (i.e., the reshoring/Asia/firm-level implementation-barrier scope conditions defined in this thesis's own inclusion rules) in a transparent, replicable way.
