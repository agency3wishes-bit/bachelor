## Methodological procedure established from available search snippets

Publisher/repository PDFs (researchgate.net, d-nb.info, miguelangelmartinez.net hosting an earlier 2000 version) were identified via search but not directly fetched per the task's constraints; the following synthesizes converging WebSearch summaries of the monograph's content, including summaries that draw on the closely related and frequently co-cited Mayring (2000) paper describing the same step models (the 2014 monograph is a book-length elaboration of the same core procedures Mayring introduced in 2000).

**1. General definition.** Qualitative content analysis (QCA) is described as a systematic method for structuring and interpreting textual material by coding meaning-bearing units of text and organizing them into analytically meaningful categories. It is explicitly rule-bound and step-by-step rather than a purely free interpretive reading — categories and coding rules are defined in advance (for deductive work) or built up systematically from the material (for inductive work), and the assignment of text passages to categories follows explicit procedures rather than ad hoc judgment.

**2. Core fundamental ideas (per search synopsis):** fitting the material into a model of communication to determine what kinds of inferences the analysis should address; analyzing the material step by step, following explicit rules of procedure (rather than analyzing the whole text at once); and developing/revising the category system through iterative feedback loops during the coding process.

**3. Deductive category application (step model).** For deductive (theory-driven) category development, Mayring's approach requires explicit definitions, examples, and coding rules for each category, specifying exactly under what conditions a text passage should be assigned to a given category — these definitions, examples, and rules are compiled into a "coding agenda." Search results reference a "step model of deductive category application" (a diagrammed procedure, originally from Mayring 2000, reused/updated in the 2014 monograph) but the exact number and wording of the individual steps was not independently confirmed in this search round beyond the general description of building/applying a coding agenda; treat the specific step count as UNVERIFIED.

**4. Inductive category development (step model).** In parallel, Mayring describes an inductive procedure in which categories are tentatively derived directly from the material (rather than from prior theory) and then progressively refined through the same kind of feedback-loop revision — categories are revised, consolidated into main categories, and checked for reliability as the coding proceeds. A parallel "step model of inductive category development" is referenced in search results but, again, exact step wording/count was not independently confirmed.

**5. Hybrid deductive–inductive procedure.** Consistent with the corpus's own characterization ("hybrid deductive–inductive category-development procedure"), the search summaries confirm that Mayring's overall framework treats deductive category application and inductive category development as complementary rather than mutually exclusive: an analysis can begin with theory-derived (deductive) categories — e.g., in this thesis's case, the four a priori framework categories (Regulatory/Institutional, Cultural/Organisational, Cost/Operational, Asset/Capability) — while also allowing new categories or sub-categories to emerge inductively from the coded material where the a priori framework does not fully capture the data. This hybrid logic is the most directly relevant procedural element for the thesis's own coding approach.

**6. Quality criteria.** One search summary notes that Mayring derived a set of quality criteria for QCA adapted from classical validity/reliability criteria (reported as "eight" criteria in one summary), but the specific list of these eight criteria was not retrieved and should be treated as UNVERIFIED pending full-text access.
