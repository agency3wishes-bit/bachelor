## Methodological procedure established from available search snippets
Confidence: consistent across multiple independent secondary sources (PubMed abstract, PRISMA statement website description as indexed, PMC listing pages, library guides), but no full paragraph of the primary text was directly read (BMJ, PMC/NCBI, and prisma-statement.org all returned HTTP 403 or were otherwise blocked when fetched directly in this session).

**1. Purpose and relationship to the Statement (M03).** M05 is explicitly the explanatory/elaboration companion to the concise PRISMA 2020 Statement. Per convergent search summaries, the paper "explains why reporting of each item is recommended, presents bullet points that detail the reporting recommendations, and presents examples from published reviews." Multiple sources state it is "strongly recommended" that the Statement (M03) be read together with the Explanation and Elaboration paper (M05), since M05 is intended "to enhance the use, understanding and dissemination of the PRISMA 2020 statement."

**2. Structure.** The PRISMA 2020 checklist itself organizes 27 items (some with sub-items) across seven sections (per multiple converging summaries: title, abstract, introduction, methods, results, discussion, and other information). M05 works through the checklist item by item; for each item it (a) explains the rationale for why that item should be reported, (b) gives bullet-pointed reporting recommendations, and (c) provides an exemplar — a real excerpt from a published systematic review illustrating compliant reporting. This item-by-item, rationale-plus-exemplar structure is described in search summaries as "new to PRISMA 2020," intended to facilitate uptake of the guideline.

**3. Specific items with corroborated content (useful for this thesis's Methodology chapter):**
- **Item 5 — Eligibility criteria:** requires authors to specify the inclusion and exclusion criteria for the review (e.g., criteria that could cover study design, population/context, and time frame in a given review) and how included studies were grouped for synthesis. For this thesis, this is the item that would justify explicitly stating the reshoring-definition eligibility rule (Asian host country to home-country return only; excluding China+1, re-offshoring, nearshoring without return, and foreign-to-foreign relocation) as a reportable, PRISMA-compliant eligibility criterion.
- **Item 6 — Information sources:** requires authors to specify all databases, registers, websites, organisations, and reference lists consulted, and the date each was last searched.
- **Item 7 — Search strategy:** requires authors to present the **full search strategies for all databases, registers and websites**, including filters and limits used — a notable strengthening compared with PRISMA 2009, which did not require full reproducible search strings. Search summaries note this level of detail is normally placed in an appendix/supplementary material rather than the main text, which is directly relevant to how this thesis's own Methodology chapter should present its database search strings.

**4. Field applicability.** All corroborated descriptions of M05 come from clinical/health-sciences-oriented indexing (PubMed, PMC, PRISMA statement website, university library guides for evidence synthesis). No search result specifically addressed adaptation of PRISMA reporting guidance to business/management systematic reviews; the general reporting logic (explicit eligibility criteria, documented information sources, reproducible search strategies, transparent flow of records) is domain-neutral as described, but no source explicitly discusses non-clinical/management-research application.
